[ 더페이지 3D 초경량 변환기 - 미니 앱 사용 안내 ]

1. 시작하기 (최초 1회):
   - [[실행] 더페이지 3D 변환기.bat] 파일을 더블클릭합니다.
   - 모니터 오른쪽 하단 구석에 작고 세련된 미니 창이 나타납니다.
   - 작업표시줄(시작바)의 아이콘을 마우스 우클릭 -> [작업 표시줄에 고정]을 클릭해 두세요.

2. 매일 작업할 때:
   - 시작바의 아이콘을 누르면 오른쪽 구석에 작은 창이 뜹니다.
   - 작업한 폴더 또는 3D 파일(OBJ, MTL, JPG)을 상자 위로 마우스로 툭 던지세요.
   - 3초 만에 7MB 초경량 GLB가 포함된 완성형 ZIP 파일이 자동 생성됩니다!

※ 상단의 📌(핀) 아이콘을 켜두시면 다른 프로그램을 작업할 때도 창이 뒤로 숨지 않고 항상 위에 떠 있습니다.
